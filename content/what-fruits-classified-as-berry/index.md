Strawberry is not a berry. Banana is.

Most people define berry by how it tastes and looks which certainly strawberry is considered as berry. However, what classifies as a berry from biological definition is a fleshy fruit (buah yang ada dagingnya) that develops from a single flower with one ovary. To explain it simply, berry is a fruit that contains many seeds inside it.

Strawberry has seeds on the outside, so it is not a berry. Banana has seeds inside, so it is a berry.

Other fruits categorized as berry are:

- Grapes
- Currants
- Tomatoes
- Blueberries
- Banana
