After the controversial issue is going on on Raymond Chin's repository, people are debating about open source licenses. Here are few widely used open source licenses:

1. MIT

- Do whatever you want with the code.
- You're allowed to use this inside your closed-source proprietary software.
- You need to retain the copyright notice

2. GNU Lesser General Public License

- You can use this library or software for free, but if you edit those libraries, publish those changes.
- Popular projects such as FFmpeg, 7zip.

3. BSD 3-Clause

- Do whatever you want, but don't use my project name to promote your stuff. It's ok to add attribution like `Powered by [project name]`. You can't repackage the software and put endorsement like "Recommended by [project name]".

4. Apache 2.0

- Similar to MIT but with extra enterprise protection. You gain a patent grant from contributors.
- If you sure someone over a patent related to the software, your licenses terminates automatically.

5. GNU General Public License v2 (GPLv2)

- This is a strong copyleft license.
- If you use this code in your project, your entire project must be open source under the same license.
