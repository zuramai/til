There are many alternatives can be used when addressing something.

### To give more specific information "*this argument...*"

In Indonesian language we use "*ini menunjukkan bahwa..*" to address something we are referring to. But it is lacking of detail and context. We can change it to a more specific word:

| | | |
| -- | -- | -- | -- |
| analysis | approach | concept | context |
| data | definition | environment | evidence |
| factor | issue | problem | function |
| measure | method | period | policy |
| principle | procedure | process | theory |
| response | sector | structure | interpretation |

E.g.

- **This approach might be...**
- **This interpretation causes the police officers to prosecute innocent people**


### Expressing the importance of the topic

Superlatives can be useful to show that the topic is important.

For example:

- (one of) the most (significant/important) causes of _______ is...
- (some of) the most (significant/important) aspects of _______ are...

#### Using adjective-noun combination

- increasing concern
- an important part
- an increasing concern
- a great/major problem

or using adverbs

- is becoming increasingly important
- has been extensively researched

### Using nouns in essay

- "*They have saved the cost of*" --> "Cost saving"
- "*They have increased the efficiency*" --> "Efficiency increase"

For exercise, try to modify this sentence:

"*There is a difference between cultures, so they need to communicate by using different strategies*"

"*A cultural differences cause people to communicate using different strategies*"

"*Cultural diversity requires the adoption of varied communication strategies*" (more formal and academic)

### Use cautious language

Instead of being dogmatic (e.g. "*These people are wrong*"), we express ourself more diplomatically, for example: "*Recent research suggests that this is not the case*."

We can also use [hedging techniques](../hedging-techniques-in-writing) to sound more polite, especially since we are unlikely to be able to cite real evidence to support our arguments.

Instead of "*Students have a very low level of basic coding knowledge due to over-dependence on AI*", we say "*Over-dependence on AI **may** have a negative effect on student coding knowledge.*"
