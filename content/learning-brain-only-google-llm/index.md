[A study](https://www.media.mit.edu/publications/your-brain-on-chatgpt/) suggest the more cognitive load used in learning process, the better we can recall the memory learned. This study compares three different method for essay writing task: Brain-only, Search Engine, and LLM-assisted approach. ***This findings*** **indicated** that the brain-only group **exhibited** the strongest neural connection, the search engine group demonstrated moderate connectivity. In contrast, LLM group **displayed** the weakest neural connection.
